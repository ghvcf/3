    上线与集成方案

    1. 表单收取邮箱：将表单 action 指向 Google Forms 或 Formspree，一次 GET/POST 即可完成收集。
    2. 定时聚合：由 GitHub Actions 每日运行抓取脚本，将结果写回 data.js／jobs.json 后自动部署。
    3. 定时推送：由 Google Apps Script 触发器读取表格，按用户方向筛选后发送邮件，适用于小范围试用。
    4. 托管：GitHub Pages、Cloudflare Pages、Netlify 均可托管纯静态站点，无需自建服务器。

    以上即文档中「数据聚合层 → 呈现层」的最小闭环：抓取、筛选、展示、推送四个环节均可在无服务器条件下实现。
